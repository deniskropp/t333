# Architecture: Spaces

## Role
Spaces are instantiated operational environments built on top of the normative kernel.

## Examples
- HelioDeck — innovation under ethical oversight
- AetherWeave — creative narrative
- ForgeWeave — code and substrate evolution

## Construction
1. Define purpose
2. Initialize Session with ArtifactStore
3. Generate typed Plan
4. Assign agents
5. Execute via ExecutionContext

## Canon Constraint
Spaces consume only abstract kernel types. Concrete bindings are injected at the edges.
